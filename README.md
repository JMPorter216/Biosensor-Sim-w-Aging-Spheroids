# SPR Sim

This Python code is designed to simulate SPR measurements in response to hormone/antibody interactions, generating spheroid secretions in response to various stimuli over time.

## Highlights

- Simulates: RU signal versus time, flow rate, spheroid size, age, cell number, antibody type, hormone type, kon/koff
- Quick demo: The demo will ask for input values for flow rate, antibody type etc.., then run a simulated stimulation and data collection, returning a sensorgram graph, with output values for total shift, concentration, etc
- Reproducibility: install dependencies with pip install ~r requirements.txt
- Tested with Python 3.11
